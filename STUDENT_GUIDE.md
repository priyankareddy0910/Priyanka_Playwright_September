# Student Guide

Hi everyone,

This project contains practice code for:

- Playwright concepts
- TypeScript basics
- JavaScript basics

## Project Setup

Run these commands from the project root:

```bash
npm install
npx playwright install
```

## Run Commands

Run all Playwright tests:

```bash
npm test
```

Run tests in headed mode:

```bash
npm run test:headed
```

Run only Playwright TypeScript concept specs:

```bash
npm run test:ts
```

Run one specific test file:

```bash
npx playwright test playwright/tests/typescript/dropdown.spec.ts
```

## Important Folders

- `playwright/tests/typescript`
